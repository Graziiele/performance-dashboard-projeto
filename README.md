📊 Product Performance Dashboard

Visão Geral do Projeto

Este projeto tem como objetivo analisar a performance de um produto a partir de dados fictícios, simulando um cenário real de negócio. O foco está na estruturação de indicadores de desempenho (KPIs), análise de resultados e geração de insights acionáveis para apoio à tomada de decisão gerencial.

O dashboard foi desenvolvido no Looker Studio, com layout previamente prototipado no Figma, garantindo clareza visual, boa usabilidade e leitura executiva dos dados.

🎯 Objetivo

Avaliar a performance do produto ao longo do tempo, identificando:

Tendências de crescimento ou queda

Produtos e canais mais eficientes

Comportamento de clientes novos vs recorrentes

Relação entre satisfação do cliente e resultados financeiros

O projeto simula análises comuns em áreas de Projetos, Performance, Varejo e Negócio.

🧱 Estrutura dos Dados

A base de dados utilizada é fictícia, com aproximadamente 5.000 registros, contendo informações de vendas, clientes, produtos e satisfação.

Principais colunas:

order_id – Identificador do pedido

date – Data da venda

product_name – Nome do produto

category – Categoria do produto

region – Região

sales_channel – Canal de venda (Loja Física, E-commerce, Franqueado)

units_sold – Quantidade vendida

unit_price – Preço unitário

revenue – Receita

customer_type – Cliente novo ou recorrente

satisfaction_score – Nota de satisfação do cliente
